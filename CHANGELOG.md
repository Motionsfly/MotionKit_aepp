# MotionKit - Change log

All MotionKit (After Effects + Premiere Pro) releases. The plugin reads `update.json` in this repo to tell users about new versions.

## v2.37.0 - 2026-10-22 - Editor templates + GitHub updates
- **New:** 28 editor timeline templates (Elements > Timeline): render bar green / red, render queue, trim in / out, split layer, drag file to timeline, pre-compose, pick whip, markers, time remap, audio waveform, expression error, missing footage, timecode, RAM preview loop and more
- **New:** 27 editor UI templates (Elements > UI Animation): error + warning dialogs, render complete toast, render progress window, out of memory, missing fonts, drag & drop import, effect search typing, drag effect onto layer, effect controls, color picker, export format, encoder queue, undo history, context menu and more
- **New:** update checker - header update button + Settings > About > Updates
- **New:** "What's new" window after every update

## v2.36.0 - 2026-10-21 - Money elements
- **New:** 243 money templates in every Elements tab

## v2.35.0 - 2026-10-21 - Viral tab redesign
- **Improved:** Grid + Split presets drawer and settings tabs
- **New:** corner / box reveal grid animations, 21 Reveal presets
- **New:** 40 editor timeline templates
- **Fix:** theme accent colors are perfect circles
