# MotionKit by Motionsfly

All-in-one panel for **After Effects** and **Premiere Pro** (Windows + macOS).

## Latest version: v2.37.0 (22 Oct 2026)

**New in v2.37**
- 55 editor templates in Elements > Timeline and UI Animation: render bar green / red, render queue, trim, split, drag & drop files, effect search, error + warning dialogs and more
- Update checker: MotionKit tells you when a new version is out (green Update button in the panel header)
- "What's new" window after every update

**Also new since v2.31**
- **v2.36** - 243 money elements (coins, bills, charts, payments ...) in 8 Elements tabs
- **v2.35** - Viral tab redesign + corner / box reveal grid animations + 40 editor timeline templates
- **v2.34** - Editor Mode > Viral: Grid Transition + Split Screen Studio
- **v2.33** - AI Mode: Create Image + API keys in Settings
- **v2.32** - 60 transitions, cursors, explosions, FX Search palette, screen color picker
- **v2.31** - AI Mode (BETA): Direct Chat, BG Remove, AI Enhancer

Full list: [CHANGELOG.md](CHANGELOG.md)

## How to update (existing buyers)
1. Open your **Gumroad library**: https://app.gumroad.com/library
2. Download the new **MotionKit** zip
3. Close After Effects / Premiere Pro and run the installer again (Windows: `Install on Windows.bat`, Mac: `Install on Mac.command`)
4. Your settings, presets and license stay
